# AI Usage Report

## Какие части делались с AI

1. Настройка проекта Vite + React + TypeScript
2. Настройка Tailwind CSS
3. Настройка TanStack Router и TanStack Query
4. Настройка MSW с моками
5. Создание типов TypeScript для аукционов
6. Создание страниц: список, детальная, ставки
7. Реализация фильтров с синхронизацией URL
8. Реализация пагинации
9. Реализация формы ставки с React Hook Form + Zod
10. Prefetch при наведении
11. Интеграция react-hot-toast

## Какие решения приняты самостоятельно

1. Выбор Tailwind CSS для стилизации
2. Использование axios для API клиента
3. Структура папок согласно Feature-Sliced Design
4. Использование Zustand (не потребовалось, так как TanStack Query покрывает все кейсы)
5. Типизация всех компонентов
6. Обработка ошибок и edge cases
7. Адаптивный дизайн

## Какие AI-предложения были отклонены

1. Предложение использовать Redux вместо TanStack Query - отклонено, так как TanStack Query лучше подходит для работы с API
2. Предложение использовать Material-UI - отклонено, так как выбрали Tailwind CSS для большего контроля над стилями
3. Предложение добавить сложную анимацию - отклонено, так как не требуется по заданию
4. Предложение использовать Next.js - отклонено, так как задание требует SPA

## Какие места проверялись особенно внимательно

1. Соответствие OpenAPI-схеме
2. Валидация форм с Zod
3. Обработка ошибок 422
4. Обновление состояния в MSW после мутаций
5. Инвалидация кэша после мутаций
6. Hide состояния (hide_bets_history, hide_points_address_and_contacts)
7. Типизация всех компонентов и функций
8. Синхронизация фильтров с URL

## Какие риски остались

1. **MSW работает только в development режиме** - для production нужно будет заменить на реальный API
2. **Мок-данные не покрывают все edge cases** - например, большое количество страниц с пагинацией
3. **Нет тестов** - в задании сказано "желательно", но время ограничено
4. **Нет аутентификации** - не требуется по заданию
5. **Нет обработки всех возможных ошибок API** - только базовые
